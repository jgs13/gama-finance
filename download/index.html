Baixar APK para Android

Após baixar, abra o arquivo e siga as instruções do Android para instalar. Para atualizar, instale por cima da versão existente, sem desinstalar o aplicativo.

Importante: mantenha um backup dos seus dados. A instalação por cima preserva os dados locais quando a assinatura do aplicativo é a mesma. Não desinstale a versão atual antes de atualizar.

Se o Android bloquear a instalação, autorize temporariamente a instalação de apps pelo navegador ou gerenciador de arquivos que abriu o APK.
