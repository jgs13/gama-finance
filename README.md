# GAMA FINANCE

Aplicativo web instalável (PWA) para controle financeiro pessoal e profissional.

## Recursos da primeira versão
- Painel mensal com receitas, despesas, saldo e pendências.
- Lançamentos de receitas e despesas, com status pago/recebido ou pendente.
- Fontes de renda com previsões semanais, quinzenais e mensais.
- Calendário financeiro.
- Cadastro de cartões, limites, fechamento e vencimento.
- Contas a pagar e acompanhamento de vencimentos.
- Análises por categoria e indicadores do mês.
- Benefícios e descontos informativos, sem abatimento automático do salário líquido.
- Backup e restauração em JSON.
- Interface responsiva e suporte básico a instalação/offline via PWA.

## Publicação
Publique o conteúdo deste repositório usando GitHub Pages (branch `main`, pasta `/root`). Depois, abra a URL HTTPS no Android e use o menu do navegador para instalar/adicionar à tela inicial.

## Importante
Esta entrega é um PWA, não um APK Android nativo. Os dados são armazenados localmente no navegador/dispositivo, sem login ou sincronização em nuvem. Faça backups regulares.
